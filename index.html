The problem

Every legacy workbook has a maintainer nobody hired.

Every finance team, plant floor, and ops department has one: a workbook nobody remembers building, doing work nobody wants to inherit. Thousands of lines of Sub and Function procedures written for a version of Excel that's two decades gone, held together by named ranges and institutional memory. Opening the VBA Editor feels like defusing something — so mostly, nobody does. The workbook just keeps running, untouched, until it breaks.

Why Claude, and not a rewrite

Anthropic's own Claude for Excel add-in can't reach VBA at all — it's built on Office.js, which has no API for the VBA project. VBABridge closes that gap by driving Excel the same way the Editor itself does: COM automation, live, on your machine.

How it connects

Four steps, no export in sight.

Claude loads VBABridge

As an MCP server, from Claude Desktop or Claude Code — one install, one config entry.

It attaches to your open Excel session

Over COM automation — the same interface the VBA Editor itself is built on. No new Excel instance, no headless copy.

Claude reads, writes, and runs your actual VBA project

Changes land in the Editor immediately. Open Alt+F11 mid-conversation and watch the module update live.

Nothing leaves your machine

There's no upload and no cloud copy of your workbook. Claude is just another editor attached to the session you already have open.

Requirements

Windows and Excel. On purpose.

VBABridge drives Excel over COM automation — the same mechanism the VBA Editor itself is built on. There's no equivalent on macOS or in Excel Online, so this is a Windows-only tool, deliberately, rather than a weaker cross-platform one.

▸

Desktop Excel, any recent version. The workbook must already be open — VBABridge attaches to your session, it doesn't open files itself.

▸

One manual step, once: enabling "Trust access to the VBA project object model" in Excel's Trust Center. That's Microsoft's own gate on programmatic access — not a VBABridge limitation, and not something any installer is allowed to script around.

▸

A one-click installer handles the rest — checks Python, installs the package properly, and wires up Claude Desktop's config in one run.
